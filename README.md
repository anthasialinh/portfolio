## 🏛️ Design Identity & Visual Direction

- **Typography:**
  - **Fraunces** (Serif) for display headlines, section headers, project titles, and editorial quotes.
  - **Sora** (Sans-Serif) for body copy, navigation, tables, metadata labels, and buttons.
- **Color Palette (Fraunces & Sora Brand Kit):**
  - Background: `#FFFFFF`
  - Primary text: `#44000E` (Deep Wine)
  - Primary accent: `#BE185D` (Berry)
  - Secondary accent: `#880034` (Plum)
  - Light surface: `#F8F6F6` (Alabaster)
  - Border: `#E8E0E2`
- **Aesthetic Principles:**
  - Generous whitespace, crisp 1px borders, subtle separators, intellectual data visualization line-work.
  - Strict avoidance of generic corporate templates, glassmorphism, or artificial skill percentage bars.
